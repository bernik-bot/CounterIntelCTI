## 📌 About The Project

**CounterIntelCTI** is an enterprise-grade, comprehensive threat intelligence directory strictly designed for **Defensive Security** and **Cyber Threat Intelligence (CTI)**:

- 🕶️ **Dark Web Intelligence (DARKINT)** — Ransomware DLS blogs, cybercrime forums, pastebins, and hidden services
- 🌐 **Open Source Intelligence (OSINT)** — Threat feeds, ransomware trackers, malware sandboxes, attack surface discovery, and identity attribution
- 📱 **Social Media Intelligence (SOCMINT)** — Threat actor communications and researcher channels across Telegram, Discord, Twitter/X, and Reddit
- 🔎 **Threat Hunting & Detection** — MITRE ATT&CK, Sigma HQ, YARA rules, and Living-off-the-Land (LOLBAS) execution catalogs
